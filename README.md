# UART Bootloader for STM32L476RG

A custom two-stage bootloader for the STM32L476RG (NUCLEO-L476RG), built from scratch to understand to how vector table relocation, memory-mapped flash regions, and the bootloader-to-application handoff actually work at the hardware level.
